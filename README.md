# Calculadora Java

Una calculadora simple pero funcional construida con Java Swing, que proporciona una interfaz gráfica de usuario limpia, para operaciones aritméticas básicas.


![Vista previa de la calculadora](calcuJava-1.PNG)

## 🔍 Características

* Operaciones aritméticas básicas:
  * Suma (+)
  * Resta (-)
  * Multiplicación (*)
  * División (/)
  * Porcentaje (%)
  * Elevado (^)
  * Factorial (!)
* Función de borrado (C)
* Función de boton retroceso (←)
* Soporte para números negativos
* Manejo de errores para división por cero
* Interfaz amigable con colores distintivos para botones numéricos y operaciones

## 💻 Requisitos Previos

* Java Runtime Environment (JRE)
* Java Development Kit (JDK) para desarrollo



## 📖 Guía de Uso

1. Inicia la calculadora
2. Usa los botones numéricos para ingresar números
3. Selecciona una operación (+, -, *, /, %)
4. Ingresa el segundo número
5. Presiona = para ver el resultado
6. Para boton de Elevado presiona el primer número luego presiona ^ y luego el número al lo quieras elevar
7. Para boton de Factorial, presiona el número al que quieras calcular su factorial y luego presiona ! automáticamente tendrás el resultado
8. Usa C para limpiar y comenzar un nuevo cálculo
9. Usa ← pora retroceder y borrar el último elemento introducido
10. Para números negativos, presiona - antes de ingresar el número

## 🛠️ Detalles Técnicos

* Construido usando Java Swing para la GUI
* Implementa ActionListener para el manejo de eventos de botones
* Utiliza BorderLayout y GridLayout para la organización de componentes
* Estilización personalizada de botones con diferentes colores
* Personalización de fuentes para mejor visibilidad

# 🖩  VERSIÓN 2 CALCULADORA JAVA MULTI-BASE 
  # 🖩 Calculadora Científica Multi-Base

Una calculadora científica implementada en Java con capacidad para realizar operaciones en diferentes bases numéricas (binario, octal, decimal y hexadecimal).

## 🚀 Características

- **Múltiples Bases Numéricas**
  - Binario (Base 2)
  - Octal (Base 8)
  - Decimal (Base 10)
  - Hexadecimal (Base 16)

- **Operaciones Soportadas**
  - Operaciones básicas (+, -, ×, ÷)
  - Potencias (^)
  - Porcentaje (%)
  - Factorial (!)
  - Conversión entre bases numéricas

- **Características de la Interfaz**
  - Interfaz gráfica intuitiva
  - Display con formato adaptado a cada base
  - Panel informativo de la base actual
  - Botones con códigos de colores para mejor usabilidad
  - Botones especiales para números hexadecimales (A-F)

## 🛠️ Tecnologías Utilizadas

- Java
- Swing (para la interfaz gráfica)
- AWT (para el diseño y eventos)
- Expresiones Regulares (para el parsing de operaciones)

## 📋 Requisitos Previos

- Java JDK 8 o superior
- IDE compatible con Java (Eclipse, IntelliJ, NetBeans)

## 🔧 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/mayrabpi/calculadora-cientifica.git
```

2. Abre el proyecto en tu IDE favorito

3. Ejecuta la clase principal `Main.java`

## 💻 Uso

1. Selecciona la base numérica deseada (BIN, OCT, DEC, HEX)
2. Ingresa los números usando el teclado numérico
3. Para números hexadecimales, usa los botones A-F
4. Selecciona la operación a realizar (+.-,*,/,^,!)
5. Presiona = para obtener el resultado
6. El resultado se mostrará en la base numérica actual
